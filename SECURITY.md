| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

If you discover a security vulnerability, evaluation desynchronization, or denial-of-service vector within `finite-rule-provenance`, please report it responsibly by contacting Lofrano Tecnologia at `security@lofrano.com.br`.

Please include:
1. Detailed description of the vulnerability or boundary condition bypass.
2. Minimal reproducing Datalog program or proof JSON payload.
3. Observed evaluation behavior versus expected bounded outcome.

We review incoming security reports promptly and deliver coordinated remediation.
